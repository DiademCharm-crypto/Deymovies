DEYMFLIX

App files for the v1.4i build
deymflix-screens-1.0.zip
The whole app code as a Sketchware local library: My Downloads, the offline player and all MainActivity logic (splash, JS bridge, download flow, fullscreen). Libraries live outside the project, so nothing can wipe them.
Download the screens library
After downloading, open the zip and put the two files inside (classes.jar + classes.dex) in:
/storage/emulated/0/.sketchware/libs/local_libs/deymflix-screens-1.0/
Create the folder deymflix-screens-1.0 if it does not exist (enable "show hidden files" to see .sketchware). Then register the library in Sketchware once -- the exact steps are in SKETCHWARE-v1.4-GUIDE.md.

Each activity keeps only one line:
MainActivity onCreate -> MainScreen85.install(this);
MainActivity back -> MainScreen85.back(this);
MainActivity resume -> MainScreen85.resume(this);
Downloads -> DlScreen85.show(this);
Player -> LocalPlayer85.show(this);
